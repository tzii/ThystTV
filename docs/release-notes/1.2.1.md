# ThystTV 1.2.1

ThystTV 1.2.1 is a focused compatibility and reliability release. It syncs a small set of verified upstream Xtra fixes, repairs two download/bookmark regressions, and hardens how release candidates are built, verified, and promoted.

## Compatibility fixes

- Bookmark VOD expiry now follows Twitch's current retention policy: 7 days for regular accounts, 14 days for Affiliates, and 60 days for Partner/Prime/Turbo accounts (manual ports from upstream Xtra `627d440f` and `15dd7d9e`).
- Stream results with both broadcaster ID and login missing are filtered before display (manual port from upstream Xtra `cfa61fc8`).
- USERNOTICE chat events without message text keep their `msg-id` so subscription, gift, and raid handling stays correct (manual port from upstream Xtra `ac0afa3d`).
- Twitch GraphQL and playback-token requests use the canonical no-trailing-slash endpoint (manual port from upstream Xtra `345cff59`).
- Downloaded video thumbnails update correctly after moving downloaded files, and channel point reward costs use locale-aware formatting (manual ports from upstream Xtra `12a8fac5`).

These are the same ports landed in PR #12, re-verified against the 1.2.1 baseline.

## Offline bookmarks

Saved bookmarks and the Downloads tab stay reachable when the device is offline or bookmark metadata cannot refresh. Refreshes are serialized and deferred instead of blocking Saved/Downloads access. This change is ThystTV-authored work in response to upstream Xtra issue #1007; it is not a port of an upstream commit.

## 7TV channel emotes

Channel emotes now load from the referenced `/v3/emote-sets/{setId}` endpoint when the channel response omits the embedded emote set or returns it empty (manual port from upstream Xtra `9c47305f8`).

## Video downloads

Partial video downloads now select whole HLS segments by explicit interval overlap, so a requested start time that falls inside a segment includes that segment instead of skipping or clipping it (manual port from upstream Xtra `8a8b99c5b`). Selection metadata is computed once and shared by every download output path; an invalid range leaves the download pending and retryable instead of fabricating a start position.

After upgrading, delete and restart any unfinished downloads begun on ThystTV 1.2.0 rather than resuming them.

## Bookmark retention estimates

Bookmark expiry estimates for regular accounts changed from 14 days to 7 days to match Twitch's current regular-account VOD retention. This affects how bookmark expiry is displayed and sorted only. ThystTV never deletes Twitch content as part of this change.

## Release verification

Local release builds remain unsigned. Signed release candidates are produced by CI, and promotion to a published release requires exact-byte verification of the APK, its SHA-256 checksum, and the official signing certificate against the release manifest. Follow the [APK verification guide](../APK_VERIFICATION.md) to verify a download before installing.

## Website and documentation

The README and GitHub Pages site now use current download, trust, and verification instructions: releases/latest links, an APK verification guide, distribution policy, security policy, and the living upstream sync ledger. Stale branch-era copy and hardcoded repository metrics were removed.

## Known scope and deferred upstream work

Deferred from 1.2 remain deferred: broad upstream player rewrites, Hilt removal, generated GraphQL query churn, network library refactors, and repo-wide rename churn. No release tag or publication happens from this branch; promotion follows the documented release process after merge.
