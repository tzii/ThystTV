- [ ] **Step 1: Add canonical/social metadata and inline theme bootstrap before CSS**

Inside `<head>`, before the stylesheet, add:

```html
<link rel="canonical" href="https://tzii.github.io/ThystTV/">
<meta property="og:type" content="website">
<meta property="og:title" content="ThystTV — Twitch client for Android">
<meta property="og:description" content="Open-source Android Twitch viewing with floating chat, local stats, and polished playback controls.">
<meta property="og:url" content="https://tzii.github.io/ThystTV/">
<meta property="og:image" content="https://tzii.github.io/ThystTV/images/readme/website-preview.png">
<meta name="twitter:card" content="summary_large_image">
<meta name="twitter:title" content="ThystTV — Twitch client for Android">
<meta name="twitter:description" content="Open-source Android Twitch viewing with floating chat and polished playback controls.">
<meta name="twitter:image" content="https://tzii.github.io/ThystTV/images/readme/website-preview.png">
<script>
  (() => {
    try {
      const requested = new URLSearchParams(location.search).get("theme");
      const stored = localStorage.getItem("thysttv-theme");
      const preferred = matchMedia("(prefers-color-scheme: dark)").matches ? "dark" : "light";
      document.documentElement.dataset.theme =
        requested === "dark" || requested === "light" ? requested : stored || preferred;
    } catch (_) {
      document.documentElement.dataset.theme = "light";
    }
  })();
</script>
```

Keep `script.js` responsible for updating button state and persisting later user changes, but make its initialization read the already-applied `data-theme` instead of recalculating a different initial theme.
