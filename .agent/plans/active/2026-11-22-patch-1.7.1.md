#120, #121), the shared upstream Helix timeout bug, and upstream's German translation

## Risks

- `/timeout` now refuses arguments Helix used to receive silently; the GQL path is unchanged.
- The clip/VoD chat download now swallows chat failures (except cancellation): a download
  that used to fail outright ends as Pending instead.
- Settings restore no longer copies arbitrary bytes over the preferences file; a backup with
  a value type outside SharedPreferences' six is skipped for that key.
- Pinch: controls fade during a pinch (behavior change, gesture-QA area). The arbiter change
  only affects pinches with three or more fingers.
- German: wording changes only; no ThystTV-only string touched.

Risk level: medium (gesture area); the other branches are low.

## Decisions

- Decision: defer #118 (sign-in theme on a live dark-mode change).
  Reason: restyling the screen without recreating it means re-theming every view around the
  live WebView; recreating it loses the 2FA progress that 1.7.0 set out to keep. Minor.
  Alternatives considered: re-applying only WebView force-dark and bar icons (inconsistent).
- Decision: defer #119 (launcher trampoline theme).
  Reason: unverified on a device, and `Theme.NoDisplay` changes how Android 12+ shows the
  splash screen for a cold start; needs a light/dark device check before changing.
- Decision: restore settings through the editor rather than restarting the process.
  Reason: no lost writes or async locale storage racing an exit, values apply in memory at
  once, and a non-backup `.xml` can be rejected. The database branch still restarts.
- Decision: hide the controls when a pinch claims instead of raising the feedback overlay.
  Reason: matches seek/speed, and the floating chat PR (#122) reworks z-order in
  `fragment_player.xml`.
- Decision: no fork feature in 1.7.1 without the maintainer's pick (UI work needs the
  research-first flow). Candidates are listed in the ledger entry.
