# Local rewind buffer

## Goal

Let viewers rewind a live stream that has no recording, using an opt-in rolling copy of
the video the player has already received.

## Non-goals

Other player backends, ad filtering, replay chat, a persistent library of saved streams.

## Current context

Branch `feat/local-dvr`, stacked on `feat/79-rewind-3-minutes`. The maintainer asked for it
as part of the features they will test on a device. Off by default.

## Risks

Risk level: high, as a player change. There is still one player and one session: a replay
goes through the existing VoD handoff. With the setting off, `beginLive` returns null and
the data source path is the existing one, so the risk sits behind the opt-in.

## Human approval

4. Service and fragment wiring, settings, source selection and replay behavior.

## Progress log

- 2026-11-03: Implemented. An emulator run with little free space had its whole cache
  cleared by Android mid-session, which led to the 1 GB free floor, recovery after a
  cleared cache, and falling back to recordings when local preparation fails.
- 2026-11-03: A public stream's replay closed after 2 minutes. Logs showed one segment
  stalling past the 12-second no-progress limit. The recorder now publishes after every
  segment and waits 60 seconds. A second run found network loss stopping the replay as it
  stops a VoD; it now keeps playing from disk. Emulator network drops confirmed: 30 seconds
  while 60 behind continues and catches up, and reaching the end offline returns to live
  once the network is back.

## Decisions

The app's cache is the right home, since the data is disposable and the system and "Clear
cache" may remove it. Twitch's live playlists reach back only about 30 seconds, so seeking
within the live source can't serve this, and larger Media3 buffers don't change that.
Teeing the player's own loads adds no requests while live; only a replay fetches anything.

The no-progress limit doesn't need to beat Exo's stuck-playlist limit: an emulator run showed
that error only when playback reached the end of the saved video, and it returns to live.

## Final PR summary draft

Adds an opt-in local rewind buffer for live streams without a usable recording, built on
the existing single-player VoD handoff.
